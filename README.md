# 🌾 AgriLens Kit

## AI-Powered Intelligent Pesticide Sprinkling System

AgriLens Kit is a smart agriculture hardware solution that uses **AI, IoT, and Computer Vision** to detect crop type, diagnose plant diseases, assess infection severity, and perform targeted pesticide spraying.

The system enables **precision farming**, reduces chemical overuse, improves crop yield, and promotes farmer safety along with environmental sustainability.

---

# 🚀 Key Highlights

- ✅ Two-stage AI pipeline: **Crop Detection → Disease Classification**
- 🎯 Targeted spraying only on infected plant regions
- 🌱 Reduced pesticide usage and environmental impact
- 📱 Farmer-friendly web/mobile dashboard
- 🌍 Globally scalable using **FAO, EPPO & ICAR standards**

---

# 🧠 How It Works

```text
Image / Video / Sound Capture
        ↓
Preprocessing (RGB → HSV, Leaf Isolation)
        ↓
Stage 1: Crop Detection (CNN)
        ↓
Stage 2: Disease Classification
        ↓
Severity Scoring (0–9 Index)
        ↓
Decision Logic
        ↓
Automated Precision Spraying
```

Soil moisture, pH, temperature, and environmental sensors help prevent over-spraying and ensure safe pesticide levels.

---

# 🧰 Tech Stack

## Hardware

- ESP32-CAM / Smartphone Camera
- Microcontroller
- Soil Moisture Sensor
- pH Sensor
- Temperature Sensor
- Sound Sensor
- Capacitive Level Sensor
- Automated Sprinkler (5V, 2A Power Supply)

## Software

- **AI/ML:** TensorFlow, PyTorch, CNNs
- **Backend:** Flask, MQTT, Firebase
- **Cloud/IoT:** ThingsBoard, LoRaWAN
- **Web App:** Next.js, Express.js, Tailwind CSS
